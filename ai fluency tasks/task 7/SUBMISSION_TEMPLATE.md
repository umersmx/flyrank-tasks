### Field 2: `Notes` (Context for Reviewers)

Copy and paste the following text into the **Notes** box:

```text
Submission for Week 3: Consistency, Not Talent (and Frame, Not Upstage) (FL-03)

Executive Summary & Deliverables:
1. The Through-Line (One-Line Claim & Content Map):
   - One-Line Claim: Generated 10 AI candidates across 4 strategic angles, evaluated trade-offs, and sharpened into: "I engineer resilient frontends for generative AI web apps—taming streaming layout shifts, token errors, and accessibility in React 19 and TypeScript."
   - Content Map: 5-stage ordered page flow (Nav -> Hero -> Proof Engine -> Standards -> The One Action).
   - Case Placement: Leads with strongest proof (Generative Streaming UI & Resilient Error Boundaries) followed by Schema-First Form Engine.
   - CTA Ladder: Every micro-CTA ladders directly up to the One Action (15-min technical walkthrough call).
   - Honest Gather-List: Detailed 8-point inventory of ready vs. need-to-capture assets (preventing build week blocks).

2. Identity Kit ("Frame, Never Upstage"):
   - Typography: Free Google Fonts pairing (Geist Sans 600/700 for headings + Inter 400/500 for body + Geist Mono for code).
   - Palette: 4 functional colors with exact hex codes (#FAFAFA warm canvas, #0F172A slate text, #64748B muted surface, #059669 emerald signal accent).
   - WCAG 2.1 Audit: Passed AA and AAA across all pairings (16.14:1 contrast ratio for primary text).
   - Standing Style Note: 2-line prompt block added to AI workspace to lock build consistency.
   - Brand Assets: Generated clean, scalable vector logo.svg and favicon.svg.

3. Kill Your Darlings (Image Curation & Rejection Notes):
   - Work Evidence: Enforced 100% real software captures (no AI-generated mockups or fake UIs).
   - Identity: Authentic natural-light photo of Muhammad Umer (no synthetic AI avatars).
   - AI Image Rejections: 3 clinical diagnostic rejection notes for AI-generated concepts (Abstract neural glow, 3D isometric card, Cyberpunk avatar), documenting why flashy AI slop was rejected in favor of quiet whitespace and real code evidence.

Master Directory: https://github.com/umersmx/flyrank-tasks/tree/main/ai%20fluency%20tasks/task%207
```

### Field 3: `Files` (What to Upload)

The brief requires:
> *"The one-line claim, the content map (pages, sections, cases, calls to action) with the 'still need to gather' list, the identity kit on one page (fonts named, palette with hex codes, the logo or favicon, the style note), and the final image set with your rejection note."*

Click **Choose Files** and upload:
1. **`THROUGH_LINE_CONTENT_MAP.md`** (or converted PDF)
2. **`IDENTITY_KIT.md`** (or converted PDF)
3. **`IMAGE_CURATION_AND_REJECTIONS.md`** (or converted PDF)
4. **`favicon.svg`** and **`logo.svg`** (Vector brand assets)
5. **`content-map-diagram.svg`** (Visual architecture flow)

Then click **Save submission**.

## 3. Evaluation Checklist (Pass / Revise)

- [x] **The claim is single and memorable**: Exactly one sharp sentence, not a paragraph.
- [x] **Ordered sections and named calls to action**: Ordered hierarchy laddering up to the One Action.
- [x] **Honest gather-list**: Clear checklist ensuring build week is unblocked.
- [x] **One or two fonts and tight palette (3-4 colors)**: Geist + Inter, 4 hex codes, contrast-tested.
- [x] **Simple logo/favicon exists with 2-line style note**: Clean SVGs + concise reusable prompt.
- [x] **Work shown with real captures & genuine rejection note**: 100% real code captures, 3 clinical AI rejection post-mortems.
