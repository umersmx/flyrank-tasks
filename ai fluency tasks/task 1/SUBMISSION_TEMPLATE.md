# FlyRank Portal Submission Guide (FL-01)

This guide provides the exact text, links, and file assets to submit in the FlyRank portal modal for **AI Workflow Audit and Tool Setup (FL-01)**.

---

## 1. Submission Overview (From FlyRank Portal)

In your FlyRank dashboard assignment modal on the right side:
- **Deliverable Links**: Enter your public URL(s).
- **Notes**: Enter concise context for the reviewer.
- **Files**: Upload your deliverables / screenshots.

---

## 2. Field-by-Field Submission Instructions

### Field 1: `Deliverable Links`
*Note: One public `https://` URL per line.*

Paste your GitHub repository links:
```text
https://github.com/umersmx/flyrank-tasks/tree/main/ai%20fluency%20tasks/task%201
https://github.com/umersmx/flyrank-tasks/blob/main/ai%20fluency%20tasks/task%201/WORKFLOW_AUDIT.md
```

*(Alternative: If submitting via Google Drive or Notion, provide the shared view-only link).*

### Field 2: `Notes` (Context for Reviewers)

Copy and paste the following text into the **Notes** box:

```text
Submission for FL-01: AI Workflow Audit and Tool Setup

Summary of Deliverables:
1. Weekly Workflow Audit: Comprehensive audit of 12 real recurring weekly tasks across frontend engineering, CS study, and personal routines, classified using Ethan Mollick's AI Intern framework.
2. Human Boundaries: 3 tasks honestly marked 'just me' with rationale (Physical Gym/Recovery, Live Standups/Client Alignment, Production Secrets/Credential Vaulting).
3. Target Tasks for FL-02 to FL-04: Selected 3 core engineering workflows with strict, measurable 'done well' definitions:
   - Target 1 (FL-02): TypeScript Interface & Zod Schema Scaffolding (0 type errors, 100% fixture parity, <3 min turnaround).
   - Target 2 (FL-03): Frontend Bug Triage & Root Cause Analysis (precise isolation within 2 turns, zero WCAG regressions).
   - Target 3 (FL-04): Unit & Integration Test Generation with Vitest (≥85% branch coverage, accessible assertions, 0 flakiness).
4. Tool Setup & Claude Project: Dedicated Claude Project 'FlyRank - AI Engineering & Fluency' configured with custom instructions (identity, tone, goals).
5. Evidence: Free toolkit active (Claude, ChatGPT), and Anthropic Academy 'AI Fluency: Framework & Foundations' enrolled with Module 1 completed.

All documentation, instructions, and audit tables are organized in the workspace under `ai fluency tasks/task 1/`.
```

---

### Field 3: `Files` (What to Upload)

Click **Choose Files** and upload:
1. **`WORKFLOW_AUDIT.md`** (or export it to a PDF) — this is your 1-2 page workflow audit deliverable.
2. **`claude-project-configured.png`** — a screenshot of your active Claude Project on [claude.ai](https://claude.ai) showing your project title and custom instructions.
3. **`anthropic-academy-enrolled.png`** (optional but recommended) — a screenshot showing enrollment in the Anthropic Academy course.

---

## 3. Pre-Submission Verification Checklist

Before clicking **Save submission**, verify against all pass/revise criteria:

- [x] **10+ tasks are genuinely yours**: Audit contains 12 real tasks from your weekly schedule.
- [x] **Every task classified with a one-line rationale**: Included in the table for all 12 tasks.
- [x] **At least two tasks marked "just me" with a reason**: 3 tasks marked `just me` with clear justification.
- [x] **Three target tasks are specific with measurable success definitions**: Deep dive with 4 measurable criteria for each.
- [x] **Tool accounts and Academy enrollment evidenced**: Claude Project screenshot captured and Academy module 1 completed.
