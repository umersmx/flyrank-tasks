# FlyRank Portal Submission Guide (Task 3)

> **Assignment**: What Are You Proving?  
> **Course Track**: General AI Fluency (Week 1) · **Phase**: Setup · **Workload**: 2h

---

## 1. Submission Overview

In your FlyRank dashboard assignment modal on the right side:
- **Deliverable Links**: Enter your public repository URLs.
- **Notes**: Enter concise context for the reviewer.
- **Files**: Upload your proof statement document or PDF.

---

## 2. Field-by-Field Submission Content

### Field 1: `Deliverable Links`
*Note: One public `https://` URL per line.*

Paste your GitHub repository links:
```text
https://github.com/umersmx/flyrank-tasks/tree/main/ai%20fluency%20tasks/task%203
https://github.com/umersmx/flyrank-tasks/blob/main/ai%20fluency%20tasks/task%203/PROOF_STATEMENT.md
```

### Field 2: `Notes` (Context for Reviewers)

Copy and paste the following text into the **Notes** box:

```text
Submission for Week 1: What Are You Proving?

Summary of Deliverables:
1. One-Paragraph Proof Statement:
"I engineer accessible, production-grade frontend interfaces for generative AI web applications using React 19, TypeScript strict mode, and resilient streaming UX patterns. I am building this portfolio for a Frontend Engineering Manager or Technical Lead at an AI-first product startup who needs an engineer who can turn unpredictable LLM token streams into dependable, WCAG 2.1 AA-compliant user experiences. The single most important action I want them to take is to book a 15-minute live technical walkthrough call to inspect my running code architecture and discuss an engineering role."

2. The One Honest Line on Why This Needs to Exist:
"A static resume or LinkedIn profile cannot prove how I handle unpredictable streaming token errors, layout shifts during LLM responses, and keyboard-accessible state machines during real generation failures—a focused interactive portfolio proves it in 30 seconds."

3. AI as Thinking Partner:
Conducted a multi-turn Socratic interview with Claude pushing back on generic 'full-stack' labels and the 'and' trap, narrowing the claim to resilient streaming UX, targeting a Frontend EM, and focusing on a live 15-minute technical walkthrough call. Full interview transcript documented in AI_INTERVIEW_LOG.md.

Repository Folder: https://github.com/umersmx/flyrank-tasks/tree/main/ai%20fluency%20tasks/task%203
```

### Field 3: `Files` (What to Upload)

The brief requires:
> *"The one paragraph proof statement (claim + person + action) plus the one-line why"*

Click **Choose Files** and upload:
1. **`PROOF_STATEMENT.md`** (located in `ai fluency tasks/task 3/PROOF_STATEMENT.md`), or export it as a PDF.
2. *(Optional)* A screenshot of your AI interview conversation with Claude from `AI_INTERVIEW_LOG.md`.

---

## 3. Evaluation Checklist (Pass / Revise)

- [x] **One primary claim is named**: Frontend AI Interface Engineering (no "and" trap).
- [x] **Audience is one specific person**: Frontend Engineering Manager / Technical Lead at an AI-first product startup.
- [x] **A single most-important action is chosen**: Book a 15-minute live technical walkthrough call.
- [x] **Could only describe your proof**: Anchored in streaming token resilience and WCAG AA accessibility.
- [x] **One honest line why**: Clearly articulates what CV/LinkedIn fails to prove.
