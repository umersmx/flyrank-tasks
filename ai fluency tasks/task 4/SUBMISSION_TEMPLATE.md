# FlyRank Portal Submission Guide (Task 4)

> **Assignment**: Frame It as Cases: Work That Speaks for Itself  
> **Course Track**: General AI Fluency (Week 2) · **Phase**: Foundations · **Workload**: 3h

## 1. Submission Overview

In your FlyRank dashboard assignment modal on the right side:
- **Deliverable Links**: Enter your public repository URLs.
- **Notes**: Enter concise context for the reviewer.
- **Files**: Upload your framed cases document or PDF.

### Field 2: `Notes` (Context for Reviewers)

Copy and paste the following text into the **Notes** box:

```text
Submission for Week 2: Frame It as Cases: Work That Speaks for Itself

Summary of Deliverables:
1. Voice Card: 'Direct. Candid. Plain. Technically precise. No buzzwords.' added as a standing instruction to Claude Project.
2. Two Framed Case Studies (Three Beats):
   - Case 1: Generative Streaming UI & Resilient Error Boundaries (handling SSE token flood, isolated component error boundaries, eliminating layout shifts, and discarding mid-stream regex parsing).
   - Case 2: Schema-First Accessible Form Validation Engine (trim-first Zod validation, WCAG 2.1 AA aria-describedby & role='alert', and in-flight submission locking).
3. Bio & Call to Action Copy: 2-sentence bio highlighting production frontends for AI tools and 1-line CTA directing to a 15-minute code walkthrough call.
4. Before / After Comparison: Contrast table demonstrating the stark difference between generic AI marketing filler ('leveraged', 'spearheaded', 'cutting-edge') and edited technical precision.
5. AI Interview Evidence: Conducted Socratic interviews with Claude to extract authentic engineering decisions, failed attempts, and honest 'next time' reflections (documented in INTERVIEW_TRANSCRIPTS.md).

Repository Folder: https://github.com/umersmx/flyrank-tasks/tree/main/ai%20fluency%20tasks/task%204
```

## 3. Evaluation Checklist (Pass / Revise)

- [x] **Framed case for each piece the sitemap calls for**: Both case studies from Task 2 sitemap fully drafted.
- [x] **Each case has the three beats**: Problem, What I Did & Decided, What Came of It.
- [x] **Sounds like a specific person**: Voice card declared, honest failures and "next time" reflections included.
- [x] **Before / after comparison included**: Direct comparison highlighting elimination of generic AI fluff.
- [x] **Speaks to one audience and points to one action**: Tailored to a Frontend EM and drives to a 15-min code walkthrough call.
